# 瑜伽动态场景稳定性修订设计

## 目标

解决实时画面中的单人重复框、杂物幽灵框、轨迹 ID 高频重建、运动人员误触发长时间停留和标签拥挤问题。当前 23～25 FPS、30～42ms 推理性能保持不退化到不可用水平。

## 观测基线

瑜伽视频经 USB 摄像头拍摄时，单人画面曾显示两人；同一人体出现重叠框；杂物区域出现大面积人体框；可见 ID 从 132、134、142 跳至 177、180、196、198；持续做动作的人在约 43 秒时触发长时间停留。

## 处理链修订

姿态后端输出先经过 `PoseObservationFilter`，再进入轨迹管理器。过滤器要求足够的可见关键点、有效躯干证据、合理面积和边界范围；高度重叠且关键点结构相似的观测只保留质量分更高者。单纯提高 YOLO 置信度不作为主要手段，以免侧身、蹲伏和横向瑜伽动作漏检。

新轨迹必须连续匹配三帧才成为确认轨迹；未确认轨迹不显示、不计人数、不进入风险引擎。确认轨迹允许短时漏检并保留 ID。每次匹配计算身体尺度归一化的关键点运动量，并写入轨迹状态。

长时间停留要求持续位于区域、框中心低速且关键点运动量低于阈值。明显肢体运动会重置本轮低活动计时，因此瑜伽、挥手和原地运动不会继承之前的停留时间直接告警。

## 配置与验证

新增 `quality` 配置段和 `tracking.min_confirmed_hits`、`risk.lingering_max_pose_motion_ratio`。纯函数和轨迹状态均使用合成观测测试。验收指标为：单人重叠观测合并为一人；低关键点杂物框被拒绝；新轨迹第三帧才发布；明显姿态运动重置停留计时；现有三类风险测试无回归。

标签改成框上方最多两行；最近事件按目标和风险类型去重，避免同一原因连续占满列表。
