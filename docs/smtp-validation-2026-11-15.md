# 通用 SMTP 接入 1.3.1 验证

验证日期：2026-11-15，北京时间。修改覆盖网页、Android 内嵌前端和云端 SMTP 客户端。

## 变更

- 删除 Gmail 专用文案及新工作区的 Gmail 默认服务器，保留已有工作区的发件配置、收件人及通知开关。
- SMTP 服务器、端口和连接加密分别配置，支持 TLS、STARTTLS 及自定义提交端口。
- 登录账号支持独立用户名，不再强制为邮箱地址；认证可自动协商 LOGIN/PLAIN 或手动选择。
- 密码/授权码加密保存、接口脱敏。相同账号下留空保留凭据，更换服务器、账号或认证方式后需重新填写。
- 测试邮件使用已保存配置，可在自动通知关闭时执行。
