# PoseGuard 1.2.0 多端验证记录

管理台使用 `poseguard.nanaoni.tech`。公开 DNS 与 HTTPS 健康检查已通过。管理端数据和目标截图要求登录。

| 验证对象 | 实测结果 |
| --- | --- |
| RK3566 | 泰山派 RK3566，NPU 驱动 0.7.2、RKNN Runtime 2.3.2、320×320 INT8。使用两段实际视频验证多人、疑似通话、正常操作和 480×800 MIPI 显示。接入 2.4 GHz 路由器后独立连接云端。 |
| 告警与证据 | 同一跟踪人员、同一风险在 100 帧时无云事件，第 101 帧产生事件。通话样本保留目标截图，长时间停留样本记录一次升级和工作人员介入。在断网状态保留队列，恢复后上传。 |
| Windows | 使用实际视频运行现有姿态推理并产生云事件。断网队列、去重、阈值及处置见测试。 |
| ESP32-S3 | 8 MB Flash、8 MB OPI PSRAM 实机完成烧录、Wi-Fi 和 HTTPS 绑定，云端收到设备心跳。此固件提供检测结果接入及告警队列。独立摄像头模型推理尚未实测。 |
| Android | Android 13 实机完成登录、事件列表、目标截图和前台测试弹窗。应用在后台时系统发布紧急测试通知，云端收到发布回执。 |
| MaixCAM | 共享传输模块已加入部署流程。实机联测待完成。 |
| iPhone | 提供 Safari 主屏幕安装与 Web Push。实机通知待验收。 |
| Gmail | 管理台提供授权和收件人设置。实际发信待账户授权后验证。 |

回归包含 178 项 Python 测试、6 项原生 C++ 测试、Go 中继测试及 6 项 Worker/D1 测试。已校验安卓签名和发布下载字节。视觉结果为辅助提醒，由工作人员确认和处置。

用户测试视频、人物截图、原始 Flash 备份和设备凭据均存放于私有位置。发布包只提供程序、模型、配置示例及运行文档。
